# WhatsApp Web Clone 🟢

WhatsApp jaisi website ka demo — HTML, CSS aur pure JavaScript se bani hai. Koi framework ya build tool nahi chahiye.

## Kaise chalayein
`index.html` ko browser mein kholo — bas! Ya kisi bhi static host pe upload karein.

## GitHub Pages pe deploy karein
1. Is repo mein `index.html` push karein
2. GitHub repo → **Settings** → **Pages**
3. Source: `main` branch, folder `/ (root)` select karein → Save
4. 1-2 minute mein site live: `https://<username>.github.io/whatsapp/`

## Features
- WhatsApp jaisa UI (light + dark mode)
- Chat list, unread badges, search, filters
- Messages bhejna, typing indicator, auto-replies
- Double ticks (sent / delivered / read)
- Mobile responsive (chat open hone pe full screen)

## Note
Ye sirf frontend demo hai — messages save nahi hote (real backend nahi hai).
